# よみほどく

書類の写真・文章から、やること・期限・金額を確認する、やさしい説明アプリです。一般のお知らせ向けの初期版です。

## できること

- カメラ・画像選択・ドラッグ＆ドロップから、日本語と英語の文字を読み取る（Tesseract.js）
- 原画像と読取り結果を見比べ、文字を修正する
- 原文の条件を残して、やること・対象・場所・期限・金額・連絡先を整理する
- 難しい用語の意味を確認する
- 原文の引用を開く、確認済みをチェックする、説明をコピーする
- 画面内の架空サンプル書類で試す

## 処理と制限

画像と文章はブラウザー内で処理します。書類内容を外部サーバーへ送信しません。OCRプログラムと言語データは公開CDNから取得するため、初回の読取りにはネット接続と準備時間が必要です。

説明は原文の抽出、定型表現の言い換え、用語辞典による整理です。生成AIによる自由な要約、年齢別の説明、音声読上げは未搭載です。認識・抽出が誤ることがあるため、原文の確認を必須にしています。入力された画像・文章・確認状態は再読み込みで消えます。OCRモデルのキャッシュ以外に永続保存は行いません。

対象は自治会・学校・イベントなど一般のお知らせです。診断、服薬、法律判断や契約解釈には使わないでください。専門文書の一部はキーワード検出時に行動や要約の表示を抑制しますが、全ての専門文書を判定する機能ではありません。

画像は20MBまで、1ページずつ。文章は16,000文字まで。PDF、複数ページ、強い手ぶれや複雑な段組、すべての手書き文字を保証するものではありません。期限の自動通知や申込みの代行はしません。

## 開発・再ビルド

配布版は index.html です。React・TypeScript・Tailwind CSS・shadcn/ui を使用しています。ソース一式は source.zip に収録しています。

1. source.zip を展開する
2. Node.js 22.13以降、pnpm 11.25を用意する
3. `pnpm install --frozen-lockfile`
4. `node scripts/build-portable.mjs public-release/index.html`
5. 生成された HTML を HTTPS の静的ホスティングに公開する

## 確認

- 日本語の架空画像によるOCRから文字修正、整理結果までを実ブラウザーで確認
- 画像ファイル選択の読取りと390px幅の操作・表示を確認
- 日付表記、OCR後の空白、元号、全角数字、金額、連絡先、否定文、改行された条件などの10ケースを検証
- TypeScript 型検査と本番配布用ビルドに成功

実機の全機種カメラ動作や、すべての書類形式を検証したものではありません。
